# Yaxest Games
Oyunlar (12): hole, blok, kosu, kule, zipla, renk, balon, karo, yilan, hafiza, birlestir, kostebek.
Yeni oyun: klasör aç (örn. `yeni/index.html`) ve `index.html` içindeki `GAMES` listesine bir satır ekle.
Netlify: klasörü Deploys sayfasına sürükle-bırak ya da GitHub deposuna bağla.
Geri bildirim formu: Netlify Forms (ücretsiz kota), mesajlar Netlify panelinde Forms bölümünde görünür.
