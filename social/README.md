# Bluesky otomatik paylaşım
1. bsky.app'te hesap aç (ücretsiz). Ayarlar > Uygulama Şifreleri > yeni şifre oluştur.
2. GitHub deposu > Settings > Secrets and variables > Actions: `BSKY_HANDLE` (örn. yaxestgames.bsky.social) ve `BSKY_APP_PASSWORD`.
3. `social/sonraki.txt` dosyasına paylaşım metnini yaz (en fazla 300 karakter) ve main'e gönder. İş akışı paylaşır.
Dosya boşken hiçbir şey paylaşılmaz.
